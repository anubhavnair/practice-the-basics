# CSS Position, Transform, Hover, and Transition Guide

## 1. CSS Position Property

The `position` property in CSS is used to control the layout and positioning of elements on a web page.

### Types of Position

### 1. Static (Default)
- This is the default position of every HTML element.
- `top`, `bottom`, `left`, and `right` properties do not affect static elements.

```css
.box {
  position: static;
}
